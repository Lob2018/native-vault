Detailed Description

Polymorphic strategy interface for OS-native credential store operations using character arrays for keys and boolean confirmations.

Windows Credential Manager implementation of the VaultStrategy interface utilizing the FFM API with proper segment reinterpretation and error handling.

See also
Wincred.h Win32 API Reference
